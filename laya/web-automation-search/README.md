# This is the updated README.md - only showing the changed lines for brevity

### Software Necessário

1. **Python 3.11+** — [python.org](https://python.org)
2. **uv** (gerenciador de pacotes) — `pip install uv` ou [astral.sh/uv](https://github.com/astral-sh/uv)
3. **Nenhum modelo externo necessário** — O LAYA roda com modelo heurístico embedido offline
4. **Chrome/Chromium** com CDP habilitado (porta 9222)
5. **Opcional: Ollama** — Caso queira usar um modelo LLM real, instale em https://ollama.ai (não é obrigatório)
